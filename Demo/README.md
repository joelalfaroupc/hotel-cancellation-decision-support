# Demo

La demo executable del projecte es pot obrir amb Docker des de la carpeta arrel
de l'entrega:

```bash
docker compose up --build
```

Un cop el contenidor estigui actiu:

- `http://localhost:8000/index.html`
- `http://localhost:8000/reserva_web.html`

El vídeo de demo no s'inclou al repositori perquè el fitxer supera el límit de
mida de GitHub per a fitxers normals. Si cal lliurar-lo com a part d'un paquet
ZIP final, es pot afegir localment a aquesta carpeta com `demo.mov`.
